My Assistant

Prototype

A personal task and goal organizer. You can add and change tasks by chatting with it, by text, photo or voice, and it checks your schedule for conflicts.

Problem
Keeping a schedule and goals organized without fiddling with forms.
Audience
Personal use.
Built with
React, Vite, installable web app (PWA). Chat uses Google Gemini.
Features
Task create, edit and delete with offline storage; goals; conflict detection.
